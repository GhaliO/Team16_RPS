This project is a real-time, webcam-based Rock-Paper-Scissors game that uses hand gesture recognition powered by MediaPipe and OpenCV. 
Players can compete against a smart AI or a friend using only hand gestures—no mouse or keyboard required.

🧠 Features
AI Opponent with Difficulty Levels:
- Easy: Random moves
- Medium: Counters your last move
- Hard: Predicts your most common move

Multiplayer Mode:
- Detects both players' hands
- Automatic gesture recognition and score tracking

Gesture Recognition:
- Detects Rock, Paper, and Scissors from hand landmarks
- color-coded UI feedback

Polished UI:
- Round tracker, real-time gesture display, and result banners
- Simple intro screens and end-game summaries

Goal
To combine computer vision, real-time interaction, and basic AI logic in a fun and accessible game.
This project is ideal for learning how machine learning and image processing can be used in interactive applications.
